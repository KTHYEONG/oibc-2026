# 검증 잡음 실험

폴드 B, all 특성, 운영 하이퍼파라미터 기준이다.

- [탐색] 실행 간 W 표준편차 ≈ 0.55%. Dataset 공유 여부와 무관하다
  (공유가 잡음을 숨긴다는 가설은 틀림).
- [탐색] 시드 3개의 범위는 실현마다 0.4~1.4%로 흔들려 잡음 임계로 부적합하다.
  대신 pooled seed sd를 쓴다(현 `compare_runs` 규칙의 근거).
- [탐색] 3-seed bag은 단일 평균보다 약 0.4% 낮다.
  이는 |F−A|의 볼록성(Jensen)으로 보장된다.
- [탐색] doy 인코딩만 바꿔도((doy−1)/365 vs doy/365.25) 평균 W가 약 1.0% 이동한다.
  코드 버전이 다른 실행끼리 비교하지 않는다.
- [탐색] bagging 제거(subsample·colsample=1)는 잡음을 0.34%로 낮추지만 W 수준은 악화된다.
- [탐색] 운영 B 폴드 재실행 차이는 −0.014%(LightGBM 멀티스레드 비결정성).
