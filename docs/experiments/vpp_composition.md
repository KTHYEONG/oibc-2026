# VPP 구성 실험

## 이론

- [재현] `|E1|+|E2| = |E1+E2| + 2·min(|E1|,|E2|)·1[E1E2<0]`이므로
  `W = W_pool(배정 무관) + Δ(배정)`이다. 구성은 Δ만 줄일 수 있다.
  목표는 두 집합이 전체의 축소판이 되도록 나누는 반클러스터링이다.

## 상쇄 손실 분해

- [재현] `prod-base-r3` OOF에 대한 `report-netting --n-random 200 --seed 0` 결과.
  OOF 규모: 폴드 A 1,256,595행·205개소, 폴드 B 2,170,645행·253개소.
  `W_pool` A 105,171,756.07, B 196,503,151.14.

| 배정 | 폴드 A Δ/W | 폴드 B Δ/W |
|---|---|---|
| current_group | 3.7370% | 2.5929% |
| geo64-s0 | 1.6681% | 0.9922% |
| 무작위 평균 | 3.1693% | 1.8412% |
| 용량 균형 평균 | 3.2082% | 1.8689% |

- [재현] 무작위 분포 상세(200회): A 평균 108,614,060.74·sd 1,056,599
  (p05 107,356,606 / p50 108,295,226 / p95 110,750,784),
  B 평균 200,189,064.76·sd 841,335
  (p05 199,111,301 / p50 200,017,123 / p95 201,833,502).
- [재현] 무작위 대비 백분위(낮을수록 좋음):
  current_group A 77.5%·B 94.0%, geo64-s0 A 0.0%·B 0.0%.
- [탐색] 초안의 무작위 평균 A 3.33%는 scratch 생성기
  (`rng.random(n)<0.5` + repair)로 측정한 값이다.
  운영 `random_assignment`(`rng.integers` + 기각 표집)와 난수열이 달라
  같은 OOF에서도 평균이 3.17%로 나온다.
  OOF 자체는 두 경로에서 완전히 동일함을 확인했다.
  무작위 기준 비교에는 운영값 3.17%를 쓴다.

## 채택 판정

- [재현] `prod-geo64-r3` vs `prod-base-r3`: all adopt,
  pooled −1.84% (CI_total −2.56~−1.11%),
  폴드 A −2.09%, B −1.59%. warm은 inconclusive(pooled −0.83%, 1% 임계 미달).
- [registry] 이전 실행 `prod-geo64-s0` vs `prod-base-r2`:
  all adopt, pooled −1.83% (CI −2.56~−1.11%),
  폴드 A −2.09%, B −1.58%, 분기 개선 A 4/5·B 5/5.
  warm은 inconclusive(pooled −0.82%).
  원인은 폴드 A에서 이력 없는 발전소 48개가 빠지면서 지리 균형이 깨지는 것이다.
- [재현] `prod-base-r3` 폴드 A bag W는 109,254,609.43으로 기존 실행과 소수 8자리까지 일치한다.
  폴드 B bag W 차이는 0.01% 이내(LightGBM 멀티스레드 비결정성).

## 기각된 대안

- [탐색] "클러스터 = 집합" 분할(지리 k-means 2분할, 동서·남북 분할):
  Δ/W A 9.8~11.6%, B 8.2~11.4%. 기각.
- [탐색] 잔차 상관 곡선(거리 구간별 중앙값 수준):
  0–2 km 0.88~0.90, 2–5 km 0.82~0.84, 20–40 km 0.53~0.56,
  80–160 km 0.28~0.33, 160 km 이상 0.12~0.16.
  폴드 A·B에서 거의 동일하다. 같은 관측소 여부의 추가 효과는 미미하다.
  용량당 오차 크기의 발전소 간 차이는 ±10% 이내다.
- [탐색] 참조 배정은 지리 불균형 기준 무작위 대비 93분위, W 기준 84~89분위다.
- [탐색] 잔차 기반 지역탐색(LS-L1): 학습 Δ/W 0.7% 수준 → 시험 1.4~2.7%. 과적합으로 기각.
- [탐색] 커널-MMD: 재시작별 B Δ/W 0.93~1.91%로 불안정하다.
  MMD 값과 실제 W의 상관은 ±0.2 수준이다. 지리 층(K=64)으로 대체한다.
- [탐색] 군집 알고리즘별 층 생성(k-means++·Ward·GMM·DBSCAN·HDBSCAN):
  지리 기반은 B 1.15~1.62%로 알고리즘 간 차이가 잡음 이내다.
  층이 커지면(DBSCAN eps=30 km, 최대 187개소) 무작위 수준으로 퇴화한다.
  잔차상관 기반 층화는 무작위와 같거나 더 나쁘다.
- [탐색] 균형 후보 45개의 기간 간 순위 상관 Spearman +0.13(6~12월 vs 1~5월).
  짝·홀 주 교차는 +0.61로 착시이므로, 균형 후보 중 잔차로 고르지 않는다.
  주 블록 교차검증은 구성 선택에 쓰지 않는다.
- [탐색] 그룹 합계 배율 보정(A→B): ref +2.8%, mmd −0.8~+0.1%. 불안정하여 기각.

## 금액 환산

- [재현] SMP가 원/kWh 단위라는 가정 하에 W 단위를 원으로 읽는다.
  각 폴드는 약 1년 분량이므로 폴드별 절감이 곧 연 환산이다.
  구성 효과(geo64-s0 vs current_group, bag 기준):
  폴드 A 약 230만원, 폴드 B 약 328만원.
  참조 배정 Δ(B 약 523만원)의 약 60%에 해당한다.
